# WhatsApp Chatbot Demo

A reusable WhatsApp booking-demo generator for clinics, spas, and salons.

## Features

- Dental, aesthetic, general clinic, spa, and salon presets
- Editable business name
- Android and iPhone mockups
- Shareable personalized demo URLs
- Downloadable MP4/WebM conversation videos

## Local Development

Requires Node.js 22.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

```bash
npm run lint
npm run build
```

## Vercel

Import the GitHub repository in Vercel. Framework detection, install, and build
settings can remain at their defaults because this is a standard Next.js app.
